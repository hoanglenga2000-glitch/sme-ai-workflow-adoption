项目使用说明

一、本地验证

进入项目根目录后，可以运行：

python -m unittest discover -s 10_Agent系统/tests -p "test_*.py"
python 10_Agent系统/evaluation/evaluate_agent.py

二、重新训练

如果需要重新训练冠军模型，可运行：

python 10_Agent系统/training/train_champion.py --force

训练结束后会输出 champion_model.joblib、model_registry.json 和相关评估报告。.joblib 文件已被 .gitignore 排除，不建议作为课堂主要提交内容。

三、接口和网页演示

uvicorn 10_Agent系统.api.app:app --host 127.0.0.1 --port 8000
streamlit run 10_Agent系统/web_demo/streamlit_app.py

四、提交前检查

- 单元测试通过。
- 数据哈希审计和特征泄漏审计有报告可查。
- 没有 GitHub token、服务器密码、SSH 私钥或 .env 进入仓库。
- 不提交 .joblib/.pkl 模型二进制。
