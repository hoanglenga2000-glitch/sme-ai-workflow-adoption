# 项目总结与后续提升路线

## 项目一句话总结

本项目从“问卷 + Kaggle 的普通课程案例”升级为“基于 Eurostat 官方公开数据、机器学习泛化验证和 Agent 原型落地”的研究型机器学习案例。主线为：**企业 AI 部署偏好与治理机制研究**。

## 已完成内容

- 完成 Eurostat 官方源数据下载、manifest 哈希记录和清洗面板构建。
- 完成 Stage 1 企业规模组机制层和 Stage 2 行业/区域外部验证层。
- 完成 Ridge、ExtraTrees 等模型训练，采用 GroupKFold 作为主口径。
- 完成数据哈希审计、特征泄漏审计、Agent 单元测试和证据索引。
- 完成 PPT、课程报告、中文提交目录和可复现说明文档。

## 核心数据与模型口径

- Stage 1：553 行面板，544 个可建模样本，36 geo，Ridge，GroupKFold R2=0.8680，MAE=1.8342。
- Stage 2：5,814 行，36 geo，50 行业，ExtraTrees，长跑复算 GroupKFold R2=0.7245，MAE=1.9646。
- 源数据链：12,770,332 行官方源数据 -> 12,341,630 行扫描 -> 856,880 行特征候选 -> 5,814 行建模面板。

## 研究边界

- 不写“千万样本直接训练”，只写“千万级官方源数据经筛选与聚合形成建模面板”。
- Stage 2 是行业/区域外部验证，不写成 SME-only。
- 问卷和访谈是辅助证据，不替代官方数据和模型主证据。
- 模型高分不写成因果证明。

## 后续提升路线

1. 继续完善数据字典和特征来源表。
2. 增加国家、行业和年份维度的误差分层分析。
3. 扩充 Agent 固定问答评估集，持续检查引用准确率和幻觉率。
4. 公开 GitHub 只保留课程案例、复现代码、公开数据和展示图表；论文和投稿材料保持私密。
