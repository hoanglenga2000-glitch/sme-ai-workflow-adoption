# GPT Image 2 全视觉版展示包

本目录是明天展示用的 v2 版本，基于公开仓库数据、模型结果和可复现图表生成。

## 最终入口

- `企业AI部署偏好与治理机制研究_机械学习完整案例展示_v2_imagegen.pptx`：可编辑 PowerPoint。
- `企业AI部署偏好与治理机制研究_机械学习完整案例展示_v2_imagegen.pdf`：PDF 展示版。
- `contact_sheet_v2.png`：14 页总览检查图。
- `preview_png/`：逐页预览图。

## 视觉与证据

- `assets_imagegen_v2/`：GPT image 2 生成的概念视觉资产，只用于封面、场景和机制表达。
- `figures/`：由数据源和模型结果生成的统计图，不使用生成图片冒充数据图。
- `source_data/`：统计图对应的 CSV 源数据。
- `slide_to_evidence_map_v2.csv`：每页 claim 与 proof object 的绑定表。
- `imagegen_prompt_manifest.csv`：GPT image 2 提示词记录。
- `ppt_quality_gate_v2.json`：PPT 结构、PDF 导出和预览生成的质量门禁。

## 使用边界

本展示包用于机器学习课程案例展示。统计结论以仓库公开数据、清洗面板、模型报告和图表源数据为准；GPT image 2 图片只承担视觉说明作用。
